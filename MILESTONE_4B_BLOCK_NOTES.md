Milestone 4B block notes

Focus:
- cloud governance hardening
- explicit abuse-download operator approval gate
- resumable audit append/read path
- retention worker helpers and legal hold support
- generic governance block that stays future-safe beyond telephony or ZIP-only workflows

This block is intentionally conservative. It does not turn the extractor into a full RBAC or archival system yet. Instead, it adds the governance hooks that later milestones can reuse inside the broader connector-first operating core.
